# bell-ha.github.io

이종하 포트폴리오 사이트 — https://bell-ha.github.io

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` · `style.css` | 포트폴리오 메인 (About · Skills · Projects) |
| `resume.html` · `resume.css` | 이력서. 브라우저에서 열어 **PDF 저장 / 인쇄** 버튼으로 출력 |
| `images/` | 프로필 사진 |
| `papers/` | 학사학위 논문 PDF |

## 이력서 수정 방법

`resume.html`의 내용을 고치고 브라우저에서 열면 됩니다.
A4 크기로 페이지가 자동 분할되어, 화면에 보이는 그대로 인쇄됩니다.

- 항목 설명은 한 줄을 넘지 않도록 35자 내외로 유지
- 페이지 분할은 `resume.html` 하단 스크립트가 자동 처리
